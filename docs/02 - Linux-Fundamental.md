# Linux Fundamentals

## Objective
Learned and practiced common Linux commands to create a foundational understanding for future projects.

## Topics Covered

### File System
Navigated through the Linux file system, created and managed files and directories, searched and located files

Commands Practiced:
pwd - Display current working directory
ls - List files and directories
cd - Change the current directory
mkdir - Create a new directory
touch - Create a new empty file
cp - Copy files or directories
cat	- Display the contents of a file
less	- View large files one page at a time
grep	- Search for text within files or command output
find	- Locate files and directories

### Users and Privileges
Learned Linux permission levels and elevated privileges

Commands Practiced:
whoami - Display the current logged-in user
id - Display user and group information
sudo - Execute commands with elevated privileges
chmod	- Modify file and directory permissions

### Processes
Monitored running processes and identified active processes and PIDs

Commands Practiced:
ps	- Display running processes
ps aux	- Display detailed information about all running processes
top	- Monitor running processes and system resource usage in real time

### Services and System Logs
Monitored background running services and investigated Linux system logs

Commands Practiced:
systemctl	- View and manage system services
journalctl	- View system logs managed by systemd

### Networking Fundamentals
Identified network interfaces, IP addresses, network connectivity, listening ports, and active network services

Commands Practiced:
ip addr (ip a)	- Display network interfaces and IP addresses
ping	- Test network connectivity to another host
ss -tuln	- Display listening TCP/UDP ports and network connections

Others: 
| (pipe) - Pass output from one command into another command

## Reflection
Introducing these Linux fundamental commands allowed me to gain knowledge that can be applied throughout the remainder of the home lab when configuring Windows logging, Sysmon, SIEM platforms, and investigating simulated security events.
